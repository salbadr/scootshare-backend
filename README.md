# Scootshare Backend
## Purpose
This repo serves as an application backend for the scootshare project. It manages supabase connection and migrations. Below are the list of commands to get started and running

## Start up
To start the app use the command 

```npm run start```

This will run the migrations and seed the data

## Create a migration

To create a new migration run

```npm create migration name_of_my_migration```

This will create a migration in the migrations folder

Then apply the migration using

```npm run apply```

## Shutdown

You can shutdown the app using

```npm run stop```

# Tech used
This project is built using Supabase
